プライバシーポリシー

Michi-Navi（道ナビ）

Michi-Navi（以下「本アプリ」）は、個人開発者 osprey74 が提供する Apple CarPlay 対応のドライブ補助アプリです。本ポリシーは、本アプリが収集・使用する情報について説明します。

1. 収集する情報

本アプリは以下の情報を使用します。

  • 位置情報（GPS）：現在地の地図表示、周辺の道の駅検索、CarPlay での走行補助表示に使用します。位置情報は端末上のみで処理され、開発者のサーバーへ送信されることはありません。
  • フォトライブラリ：道の駅フォトアルバム機能で、ユーザーが選択した写真を端末内に保存します。写真データが外部に送信されることはありません。

2. 情報の利用目的

  • 現在地の地図表示および周辺の道の駅情報の提供
  • CarPlay 画面へのドライブ補助情報の表示
  • 道の駅フォトアルバムへの写真の保存・表示

収集した情報は上記の目的以外に使用しません。

3. 第三者への情報提供

本アプリは、ユーザーの個人情報および位置情報を第三者に販売・提供・開示することはありません。

4. 利用する第三者サービス

本アプリは以下の Apple 標準フレームワークを使用します。各サービスのプライバシーポリシーはそれぞれのリンクをご確認ください。

  • Apple MapKit（地図表示・位置情報）：Apple プライバシーポリシー
  • Apple WeatherKit（気象情報）：Apple プライバシーポリシー

また、オプション設定として Google Maps API キーをユーザー自身が登録した場合、Google のタイル地図サービスを使用します。API キーは端末内にのみ保存され、開発者は参照できません。

5. データの保存・管理

  • すべてのユーザーデータ（お気に入り・到達済み記録・フォトアルバム）は端末内にのみ保存されます。
  • 開発者のサーバーへのデータ送信は一切行いません。
  • アプリを削除すると、端末内に保存されたすべてのデータが消去されます。

6. 対象年齢

本アプリは全年齢を対象としています。13歳未満のお子様から意図的に個人情報を収集することはありません。

7. プライバシーポリシーの変更

本ポリシーは予告なく変更される場合があります。変更後のポリシーはこのページに掲載された時点で効力を生じます。

8. お問い合わせ

本ポリシーに関するご質問は、GitHub リポジトリの Issue よりお問い合わせください。
